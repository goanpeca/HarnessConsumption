# Product sense

**For:** one developer who pays for Claude Max and ChatGPT Pro and wants to spend them evenly
across the work days, without opening a dashboard.

**Priorities, in order**

1. **Trustworthy numbers.** Wrong or stale data shown as current defeats the app.
2. **Glanceable.** The menu bar answers "am I fine?"; the panel answers "how much today?".
3. **Quiet.** Notifications fire once per condition and only when actionable.
4. **Harmless.** Never sign the user out of Claude Code or Codex.

**Not goals:** team dashboards, cost tracking, distribution.
